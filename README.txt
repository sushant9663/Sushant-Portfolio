# Sushant Kumar Portfolio

## Run locally
1. Open this folder in VS Code.
2. Install the Live Server extension (optional).
3. Open `index.html` with Live Server, or double-click `index.html`.

## Files
- `index.html` — website structure/content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, reveal animations and contact-form demo
- `images/sushant.jpg` — profile photo
- `assets/resume.pdf` — resume

## Contact form
The form is currently front-end only. It validates the fields and shows a success message locally. To actually receive messages, connect it to a form service or your own backend later.
